# 🤖 arXiv AI 논문 자동 요약 시스템 (Make + Gemini + Notion)

매일 아침 arXiv의 최신 AI 논문을 수집하고, Gemini AI를 통해 한국어로 요약하여 Notion 데이터베이스에 자동으로 저장하는 스마트 워크플로우 시스템입니다.

---

## 1. 프로젝트 개요
- **목적**: 매일 업데이트되는 방대한 AI 논문을 직접 확인하는 번거로움을 줄이고, 핵심 내용을 빠르게 파악하기 위함
- **주요 기능**: RSS 피드 수집, 중복 데이터 필터링, AI 요약 생성, 노션 자동 저장, 에러 핸들링

---

## 2. 자동화 워크플로우 구조

### 🖼 워크플로우 스크린샷
![Workflow Screenshot](https://via.placeholder.com/800x400?text=Make+Workflow+Screenshot+이미지를+여기에+업로드하세요)
*Make.com에서 구성한 전체 시나리오 모습*

### ⚙️ 단계별 상세 역할
1. **RSS (arXiv):** 매일 오전 8시, `cs.AI` 카테고리의 최신 논문 정보를 수집합니다.
2. **Notion (Search Objects):** 수집된 논문의 URL을 기준으로 노션 내 중복 데이터가 있는지 검색합니다.
3. **Filter:** 검색 결과가 0개(Total bundles = 0)인 경우에만 다음 단계를 실행하여 중복 저장을 방지합니다.
4. **Gemini AI:** 논문의 제목과 초록(Abstract)을 분석하여 **한국어 3줄 요약**을 생성합니다.
5. **Notion (Create Item):** 요약문, 제목, 원문 링크, 발행일시를 노션 데이터베이스에 최종 저장합니다.
6. **Error Handler (Retry):** API 일시 오류 발생 시 5분 간격으로 최대 2회 자동 재시도합니다.

## 3. 노션 데이터베이스 구성
AI가 가공한 콘텐츠가 아래와 같은 속성으로 자동 저장됩니다.

| 속성명 | 데이터 타입 | 내용 |
| :--- | :--- | :--- |
| **제목** | Title | 논문의 영문 원제 |
| **요약문** | Text | Gemini가 생성한 한국어 3줄 요약 |
| **원문 링크** | URL | arXiv 논문 상세 페이지 주소 |
| **발행일시** | Date | 논문 게시 날짜 (`parseDate` 함수 적용) |

### 🎯 주제 필터링 기준 및 선택 이유
- **주제**: arXiv `cs.AI` (Computer Science - Artificial Intelligence)
- **이유**: 최신 AI 연구 동향을 가장 빠르고 정확하게 파악할 수 있는 소스이며, 전문적인 영문 내용을 한국어로 요약하여 정보 접근성을 높이기 위함입니다.

### 🛡 에러 처리 정책 및 선택 이유
- **정책**: `Retry` 핸들러 (최대 2회 재시도, 5분 간격)
- **이유**: 네트워크 지연이나 API 일시적 과부하로 인한 워크플로우 중단을 방지하여, 사람의 개입 없이도 시스템이 안정적으로 유지되도록 설계했습니다.
